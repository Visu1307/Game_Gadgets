🎮 Game_Gadgets
Game_Gadgets is a dynamic e-commerce web application for gaming enthusiasts. 
It offers a curated collection of gaming consoles, controllers, accessories, and game discs. 
The platform includes essential e-commerce features such as user authentication, add-to-cart functionality, promo codes, and order management — all built using PHP and MySQL with a Bootstrap-powered frontend.

🛍️ Features
🔐 User Authentication
User registration and login
Secure session-based login system

🛒 Shopping Cart
Add, update, or remove items
Real-time cart total calculation

🎮 Product Catalog
View consoles, controllers, and game discs
Category-wise product listing

💸 Promo Code Integration
Apply valid promo codes for discounts

📦 Checkout System
Order summary and confirmation
Store order details in the database

📄 Order History
Track past orders after login
Track real-time status of orders

🧑‍💼 Admin Dashboard
Add/edit/delete products
Manage promo codes and stock
